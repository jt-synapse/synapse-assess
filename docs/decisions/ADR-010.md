# ADR-010 — Immutable assessment versions

**Status** Proposed for formal ratification.

**Context.** Tasks, reference answers, runtime images, policies, and rubrics evolve. A session must remain interpretable after publication of its successor.

**Decision.** Pin a session to a published package version with an image digest, stage definitions, policy and rubric versions, and separate candidate and evaluator artifact identities. Publish a new version for changes.

**Alternatives.** Mutable image tags or a global set of current tasks allow identical source submissions to be evaluated under different rules.

**Rationale.** Explicit package inputs make grading reproducible and keep assessment-specific behavior outside the platform.

**Consequences.** Package publication must resolve real artifact digests. Formal source snapshots record the assessment version and runtime digest used.

**Validation.** Validate both a database-free package and OrderFlow, reject malformed manifests, and verify that publishing a new version cannot change an existing session.
