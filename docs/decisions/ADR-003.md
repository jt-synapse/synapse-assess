# ADR-003 — Disposable assessment databases

**Status** Accepted in architecture baseline v1.1. ADR-011 specifies placement and conditional provisioning.

**Context.** Assessment 001 depends on PostgreSQL transaction and locking semantics. Session data and candidate-controlled database contents have different trust and retention requirements.

**Decision.** Give each attempt that declares PostgreSQL an independent disposable database with scoped, non-superuser credentials. Initialize it from the published migrations and seeds. Grade with a freshly initialized database in a separate evaluator environment.

**Alternatives.** Shared schemas couple candidates to a common server. SQLite changes the behavior of competing writes and locks used in this assessment.

**Rationale.** A reproducible database permits independent evaluation of concurrency and rollback while isolating failures to one attempt.

**Consequences.** Provisioning, readiness, recovery and termination include the database. The platform database holds trusted orchestration records.

**Validation.** Run independent transactions, inject a transaction failure, restart and restore with checks for committed and uncommitted rows, and verify scoped privileges and cleanup.
