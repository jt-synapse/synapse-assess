# ADR-005 — Modular FastAPI control plane

**Status** Proposed for formal ratification. M0 implements the local foundation.

**Context.** A small team must coordinate authorization, workspace access, assessment versions, and review while keeping execution isolated.

**Decision.** Keep trusted business APIs in a modular FastAPI application backed by PostgreSQL and Alembic. Use Celery and Redis for work that must outlive a request as those jobs are introduced. Keep provider integrations behind explicit interfaces.

**Alternatives.** Independently deployed business services introduce distributed coordination before the domain requires it. Running assessment code inside the API would cross the execution boundary.

**Rationale.** A modular service allows transactional orchestration while retaining a separate execution plane.

**Consequences.** Modules must enforce tenancy and ownership at each operation. Database migrations, dependency readiness, and safe error responses become deployment requirements.

**Validation.** Boot from empty volumes, migrate, exercise the web-to-API path, interrupt a dependency, recover, and run the same contract tests in CI.
