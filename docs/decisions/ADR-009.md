# ADR-009 — Separate trusted grading

**Status** Proposed for formal ratification. SEC-004 requires isolation of evaluator material.

**Context.** A submitted workspace and its database remain candidate controlled. Hidden tests, grading logic, and reference solutions are confidential.

**Decision.** After submission, pass an immutable read-only source artifact into a fresh isolated evaluation environment. Use a fresh database where required. Separate the trusted grading harness and result channel from the submitted process and deliver evaluator results only through authorized APIs.

**Alternatives.** Grading in the live candidate sandbox exposes grader materials and inherits candidate state. Accepting self-reported test output as a hidden result removes independent verification.

**Rationale.** Source identity and environmental separation make results attributable to a specific submission.

**Consequences.** The evaluator needs its own lifecycle, credentials, limits, artifact access policy, and cleanup. Stage A and Stage B remain independently reviewable.

**Validation.** Inspect the shipped candidate artifact, verify a read-only input and fresh database for each grading run, check restricted result access, and distinguish infrastructure failures from failed assessment tests.
